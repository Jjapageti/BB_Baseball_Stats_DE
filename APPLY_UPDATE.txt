적용 방법

1. 이 폴더 안의 파일과 폴더를 BB_Baseball_Stats_DE 프로젝트 최상위에 복사합니다.
2. 같은 이름의 파일은 모두 덮어씁니다.
3. data 폴더와 data/seasons/2023.json~2026.json은 그대로 둡니다.
4. 실행 중인 start_server.bat 창을 종료한 뒤 다시 실행합니다.
5. 브라우저에서 Ctrl+F5로 새로고침합니다.

v6 주요 변경

1. 선수 레이더 비교선
- 분홍 실선/채움: Spieler
- 파란 점선: Liga-Durchschnitt
- Gesamtübersicht는 전체 시즌 가중 평균과 비교
- 연도 선택은 해당 시즌 가중 평균과 비교

2. 상단 통합 검색
- 모든 화면 상단에서 Mannschaft 또는 Spieler 검색
- 선수 선택 시 통산 선수 프로필로 이동
- 팀 선택 시 해당 Saison/Liga의 Mannschaftsstatistik을 바로 엶

3. Gesamttabelle 팀 상세
- Mannschaft 이름/마크를 클릭 가능
- 해당 팀의 현재 Liga/Saison Schlagstatistik 및 Wurfstatistik 표시
- 표 헤더 클릭 정렬 지원
- URL에 team 파라미터가 기록되어 검색 결과 링크로 바로 열 수 있음
